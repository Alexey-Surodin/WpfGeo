# WpfGeo
Отрисовка гео-моделей. Каждая модель - набор координат и соответствующих им показателей удельного электрического сопротивления.

Пример отрисовки:
![Image alt](https://github.com/Alexey-Surodin/WpfGeo/blob/master/Models/Pic1.JPG)
![Image alt](https://github.com/Alexey-Surodin/WpfGeo/blob/master/Models/Pic2.JPG)

Вращение модели осуществляется мышью. Некоторые полезные свойства вынесены в контекстное меню зоны отрисовки.
Есть возможность выделения произвольных точек/слоев/уровней модели, масштабирования, выбора диапазона цветовой шкалы.
